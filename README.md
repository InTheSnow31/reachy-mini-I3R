# Generating expressive movements on Reachy Mini

Discover this experimental project on creating expressive movement and sound on the robot [Reachy Mini](https://github.com/pollen-robotics/reachy_mini?tab=readme-ov-file). It is a compact, open-source robot designed to make robotics accessible, fun, and affordable.

It is deployed by the compagny [Pollen Robotics](https://www.pollen-robotics.com/), now part of [Hugging Face](https://huggingface.co/pollen-robotics).

## 📄 This project in short

This project present 3 approaches to explore expressiveness in Reachy Mini:

1. **Adaptation** of a functional **movement** to make it expressive,  given an emotion as input;

2. **Generation** of an expressive **movement** with **sound**, given an emotion as input;

3. **Generation** of an expressive **sound**, by a neural network that is currently being trained.

Feel free to try them by launching the [main program](src/main.py) after completing the [installation process](docs/user/README.md).

### Main puropose

Reachy Mini is the embodyment of a conversationnal agent, in the shape of a robot. It is a desktop robot, supposed to communicate information to its end user, thanks to a Large Language Model (LLM).

The main idea behind the current project is to find a way to create **expressiveness**. Hence, during a **conversation** with a user, it will look more realistic and attractive.

We choose to make 3 different approaches: as it is still a reasearch project, the objective is to try different things and to **be creative**. After this process, the compagny Pollen Robotics, client of this project, will have some examples of what is possible and potentially deploy it.

### Stakes

Nowadays, when people hear about "robots", they usually think that these are the machines that will replace humans in society. However, robots are a fantastic **tool**, they can be very **useful** to humans.

Creating **social robots** is the first step to favorise they **integration** to society. A robot which can mimic human expressive behavior allows constructive exchange of knowledge. The user will feel integrated to the conversation, and thus better communicate. This process of optimized exchange allows problems to be solved faster; either by humans, robots or by their collaboration.

### Limitations

- For now, Reachy Mini is still in developpement: it is a research project.
- As there are 3 different approaches in this experimental project, you may be lost.
